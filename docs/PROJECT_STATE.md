## What works

- **Platform:** Next.js 16 (App Router), React 19, TypeScript strict, Node 26 (`>=26.0.0 <27`) / npm 12 (`>=12.0.0`). `proxy.ts` sets a CSP with nonces. Seven languages (`he` default and RTL, `ar` RTL, `en`, `ru`, `fr`, `es`, `de`), with aviation telemetry kept LTR (`AGENTS.md` section 5).
- **Scheduler (Kantorovich tiled interval engine):** 09:00-24:00 operating window; reserved blocks 30m to 45, 45m to 60, 60m to 75, 90m to 105, 120m to 150, 240m to 255; zero-waste tiling; closing-tail recovery (#276). Spec: `KANTOROVICH_SCHEDULER_SPEC.md`.
- **Booking (`/book`):** adaptive flows (3-step consumer, 2-step PRO and Fear of Flying), promotional tier bump-up ladder with the two-add-on cap, upgraded-duration grid switching (Option A, #279), flat 90m price all day (#271), tiered birthday discount up to 15% (10% on 60m, 15% on 90m/120m; 30m excluded) judged on the upgraded tier (#281, #284).
- **Offerings:** consumer flight tracks and PRO tracks (6 subscription passes: 4 consumer, 2 PRO), gift vouchers, Fear of Flying course (60 min, 690 ILS), the `/offers` page.
- **Wix Headless adapter:** writes only to the SimDream-Staging site; `npm run wix:smoke` reconciles the catalog (9 of 10 package ids mapped). Wix benefit pool allocations are audited via `npm run wix:check-benefit-pools` (`lib/wix/plan-benefit-pools.ts`). Blog V3 reads put filters inside `query`, filter by slug with `$eq` (Wix rejects `$hasSome` on a slug with HTTP 400) and by language with `$eq`, and reject a returned locale mismatch before local fallback, so a Hebrew route cannot render an English breadcrumb or JSON-LD and a translated route cannot silently render Hebrew. Worker bundle stands at 10.30 MiB UTF-8 (12.93 MiB with `\u` escapes), 3.70 MiB below the 14.00 MiB budget with `@wix/pricing-plans` 1.0.453 and `@opennextjs/cloudflare` 1.20.16 (CI job `140688021415`).
- **Wix worker and cookies:** staging runs `v1.37.0` (`6163c0a`, published 2026-11-27 22:12Z, smoke-checked 2026-11-28 01:57Z, run `46075189575`). After a publish it is verified by `npm run test:staging:content:docker` (Playwright in Docker, 32 read-only checks, staging only; last full run 32 of 32 on `v1.36.1`): a request with a cookie, every language of two blog articles with its own title and canonical, the language loop, both blog indexes, and the legal pages. `@opennextjs/cloudflare` is pinned to exactly 1.20.16 because 1.20.18 bundled the middleware cookie parser without esbuild's node-mode flag (every request with a Cookie header answered HTTP 500, "reading 'parse'"). `npm run wix:build` fails on that bundle (`scripts/wix-worker-guards.mjs`), and the CI preview, release and rollback smoke checks send a cookie and open a translated article. Dependabot ignores later versions until one passes a cookie request. A nightly job (`wix-blog-languages` inside `Nightly security scan`, last green 2026-11-28 02:11Z) checks the live Wix Blog API for every translation group in every language. Details: `docs/modules/wix-adapter.md`, `docs/modules/blog-language.md`.
- **Dependency security:** `npm audit` reports 0 vulnerabilities; the `@node-minify/core` override pins its `glob` to 14.0.6 (which brings `minimatch` 11.0.9) for the older toolchain that the `@opennextjs/cloudflare` 1.20.16 pin needs (#318, Dependabot alert #4).
- **Dependency security (Wix `i18next`):** the npm override resolves the Wix transitive `i18next` dependency to 26.3.4, removing GHSA-6jcc-5g8w-32mx without downgrading `@wix/pricing-plans`; the clean Node 26/npm 12.2 audit reports zero production vulnerabilities.
- **Quality gates:** `npm run docs:verify` passes (`GENESIS.md` covers 623 of 623 checklist items, fingerprint current). 196 Vitest test files and 67 Playwright `*.spec.ts` in 10 projects; `npm run test:quick` passes (196 files, 3,759 tests); the accessibility baseline is empty (0 axe violations).
- **Homepage visual hierarchy & telemetry aesthetics (#361):** Asymmetric bento grid for flight tracks with wide anchor blocks for Discovery and PRO; connected FMC airway flight-path timeline (WPT-01 to 03) in how-it-works; authentic cockpit photography anchors in why-us; high-contrast focal points with orange ring contrast in featured packages; WCAG 2.x AA contrast across all 3 themes (Cockpit, Daylight, Studio) with dedicated daylight overrides for orange badges and PFD stage labels.
- **Home route gate in two groups (PR #368, open):** #361's three rows with three wide cards became two source-ordered groups, each led by one anchor (Experiences, then Vouchers and Flight Tracks; PRO, then Fear of Flying and Workshops). Workshops lost its four readouts with the wide card. The anchors' readouts stay left-to-right on Hebrew and Arabic pages and wrap instead of being cut off. `tests/usability/home-route-gate.spec.ts` is the first test of this section. The copy and image questions the audit raised about #361 are in `docs/DECISIONS.md` under Open.
